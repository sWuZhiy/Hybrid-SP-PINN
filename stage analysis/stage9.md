# Stage 9：Hybrid SP-PINN

- **内容**：把 Stage 7 完整 FDM SP 自洽循环里内层 Poisson 子问题（`solve_poisson_nonlinear`，
  FDM Newton）换成 PINN（`PoissonPINNSolver` warm-start），其余**完全复用**（搭建说明 §12/§35）。
- **目的**：回答「PINN 能否承担 Poisson 子问题并保持整个 SP 自洽系统稳定」，给出 PINN 相对
  FDM 的精度 / 鲁棒性 / 效率差异——这是论文「混合 PINN」主张的核心实验。
- **关键文献**：[references.md](references.md) §D/E（Stern & Howard 1967 自洽物理基准；
  Raissi 2019 方法；Grossmann 2024 对照论证）。

## 9.1 受控对照设计

**SP 自洽的第一性原理**：平衡态 MOS 电容的静电势 φ 与量子电子密度 n 互为因果——φ 决定
Schrödinger 势能 Ec(z)=E_g/2−qφ(z)，从而决定束缚态能级与占据、产生 n(z)；n(z) 又作为
Poisson 源项反作用于 φ。平衡解是映射 φ = G(φ) 的**固定点**，其中 G =「解 Schrödinger 得
n(φ) → 解 Poisson 得 φ_new」。

**Gummel 外层**（Stage 7 已实现）把这个不动点问题显式展开为外层迭代：给定 φ 冻结 n(φ)，
解**非线性 Poisson** 得 G(φ)，残差 r = G(φ)−φ 用 Anderson 混合加速。**Stage 9 只替换 G 的
内层 Poisson 这一步**——从 FDM Newton 换成 PINN——Schrödinger 求解、密度公式、EF、Anderson
混合、网格、材料剖面全部共享同一个 `_solve_sp` 循环（源码层面同函数），从结构上保证对照的
唯一变量就是 Poisson 求解器，不可能出现「两套实现各写一份、逐渐偏离」的漂移。

**一个需要讲清的边界**：`_solve_sp` 的**初值**（纯耗尽线性 Poisson → 经典非线性 Poisson
n≡0）两个版本共用，仍是 FDM。它是「初始猜测」，不是自洽迭代的一部分——搭建说明 §35.2 的
「唯一变化」指循环内 `phi_new = Poisson(rho)`，初值不在其列。其副作用是：**弱反型**（Vg=0.5，
反型尚未开启、解≈经典解）时初值已近收敛解，循环 1 轮即满足 δ<tol 退出、PINN 的 φ_new 从未
被采纳，故 Hybrid 与 FDM 的对照在那里是「平凡完美」（都返回同一经典初值）。真正的 PINN 对照
发生在中/强反型（Vg≥1.0，多轮迭代、φ 被 PINN 实际更新）——见 9.5。

## 9.2 代码实现：策略化重构（逐文件）

### src/sp_solver.py（本阶段唯一实质改动文件）

把原 `solve_sp` 拆成「共享循环 + 可插拔内层」：

| 符号 | 职责 |
|---|---|
| `_solve_sp(device, Vg, config, phi0, make_step, tol=None, max_dphi=None)` | 共享 Gummel 外层 + Anderson 混合 + 收敛判据（δ<tol）+ 初值 + 最终自洽重算 + 外层信任域（max_dphi，仅 PINN 用）；内层由工厂返回的 `poisson_step(n, phi)` 承担 |
| `_make_fdm_poisson_step(...)` | FDM Newton 内层：`poisson_step(n, phi)` 把 φ 作 Newton 初值，Stage 7 原样 |
| `_make_pinn_poisson_step(...)` | PINN warm-start 内层 + 物理守卫（见下） |
| `solve_sp(...)` | 薄封装 → FDM 工厂，`tol` 读 `solver.tol_V`（1e-6），`max_dphi=None`（FDM 不需要） |
| `solve_sp_pinn(...)` | 薄封装 → PINN 工厂，`tol` 读 `solver.tol_V_pinn`（5e-4），`max_dphi` 读 `solver.max_dphi_V_pinn`（0.02） |

`_make_pinn_poisson_step` 的 warm-start 循环（§8.7C-2 落地）：

- 循环外持**单个** `PoissonPINNSolver`（权重跨轮复用，**不能每轮新建**——否则等价于 from-scratch
  每轮 3000 轮，既慢又破坏课程学习的物理顺序）；
- **首轮**两阶段：先以 n=0 训练经典解（建立正确势阱、φ_s 到位、界面 Robin 斜率目标变温和），
  再 `warm_start=True` 续训满 n（电子尖峰此时只是对既有解的扰动）；
- **后续轮**：`train(n, warm_start=True, n_ramp_frac=0.0, epochs=scf_epochs)`——n 相对上一轮只是
  小扰动，无需重头训练也无需 ramp（ramp 会把当前 n 从 0 重新涨一遍，反而错）。**训足固定轮数
  到收敛、不用早停**（理由见 9.4.3 的发现三）；
- **物理守卫 `_check_physical`**：每轮内层解产出后检查 (a) 输出有限（防 NaN 发散，提示改电压
  扫描初值）、(b) 表面势 φ_s 在 [min(0,Vg), max(0,Vg)] 内（容差 1 mV，拦截 φ_s<0 或 φ_s>Vg 的
  全转移伪不动点）、(c) 界面电位移连续 |R_iface|/D_ref ≤ 0.1（拦截平带/经典伪不动点——φ_s 看似
  合理但界面 Robin 残差大，说明内层解与量子密度不自洽）。违反即抛 `RuntimeError` 中止，而非假
  收敛。

## 9.3 物理模型与公式（第一性原理 + 推导链）

**内层 Poisson（FDM 与 PINN 解的是同一方程，只是数值方法不同）**：

$$ -\frac{d}{dz}\left[\varepsilon(z)\frac{d\phi}{dz}\right] = q\left[p(\phi)-n(z)-N_A\right],
\qquad p(\phi)=n_i e^{-(E_F+q\phi)/kT} $$

- 左端从**高斯定理**（∇·D=ρ，D=εE，E=−dφ/dz）的散度形式出发，对一维分层介质取积分形式；
- 右端电荷三项：冻结的量子电子 −n(z)（Schrödinger 给出）、活体经典空穴 p(φ)（平衡 Boltzmann）、
  电离受主 −N_A。指数空穴项使方程**非线性**。
- **FDM Newton**：把 p 按 d p/dφ = −q p/kT 线性化，迭代解线性三对角系统，对指数非线性无条件稳定，
  可收敛到机器精度（内层 tol_newton=1e-10）。
- **PINN**：把解参数化为 φ̄(u)=qφ/kT（u=(z−t_ox)/L_si 几何标幺），最小化 PDE 残差 + 界面 Robin
  （电位移 D 连续）的均方损失。热电压标幺使 p 退化为 p=N_A·e^{−φ̄}，从源头避开 exp 溢出。
  界面 D 连续的推导：理想氧化层 ρ_ox=0 → φ_ox 线性 → φ'_ox=(φ_s−Vg)/t_ox；D 连续 ε_si φ'_si =
  ε_ox φ'_ox 给出 Robin 条件 ε_si φ'_si(t_ox) + ε_ox(Vg−φ_s)/t_ox = 0（见 stage8.md §8.1）。

**混合循环**：外层每轮 `n = compute_carriers(φ)`（Schrödinger 对角化 + 2D DOS 占据）→
`φ_new = poisson_step(n, φ)`（PINN）→ `r = φ_new − φ` → Anderson 外推 → 信任域裁剪 → 判 δ<tol。
与 Stage 7 唯一差别就是 `poisson_step` 的实现 + 信任域（9.4.3）。

## 9.4 三个核心发现（本阶段的数值结论）

### 9.4.1 发现一：tol=1e-6 不可达，δ 被 PINN 噪声地板盖住

实测 Vg=1.0 的 SCF 残差轨迹：iter 0=13.75 mV → iter 1=3.88 mV → iter 2=0.14 mV，此后 δ 在
**~1e-5 ~ 2e-3 V** 之间振荡（典型 ~1e-4~5e-4 V），**不再单调下降**。

**根因**：FDM Newton 内层是代数求解，可到 1e-10；PINN 内层是「软约束 + 有限容量（12673 参数）
+ 随机优化（Adam）」的近似求解，单解自带 ~1e-4 V 噪声地板。δ = |G(φ)−φ| 既度量真实自洽残差、
又叠加了 PINN 单解噪声，故 δ 停在噪声地板 ~1e-4，**无论再迭代多少轮都到不了 1e-6**（会耗尽
max_iter=200）。

**结论与处置**：搭建说明「相同 tolerance=1e-6」的硬性要求被实测推翻。处置（已与用户确认）：
给 PINN 加独立容差 `solver.tol_V_pinn=5.0e-4`（≈噪声地板的 5 倍，留足裕度），FDM 仍 1e-6；
收敛判据**结构**相同（δ<tol），仅 tol 取值因内层求解器而异。这本身是一个有价值的数值结论：
**PINN 的收敛判据不能沿用 FDM 的机器精度阈值，必须以其逼近精度为下限**。

### 9.4.2 发现二：强反型从零初值发散，需电压扫描初值

实测 Vg=1.5 **从零初值**（phi0=None）：经典初值 φ_s≈1.37 V（高估，真实 ~1.08 V），由此
`compute_carriers` 得到暂态电子尖峰 **n_max≈1.15×10⁴·NA**，PINN 两阶段训练即发散（φ 输出
NaN，随后 Schrödinger 侧抛 `infs or NaNs`）。

**根因**：耗尽/经典初值在反型区会高估表面势。FDM 的 Newton 内层对这个高估产生的暂态 n 尖峰
**无条件稳定**（线性化后直接解线性系统，不依赖 n 的大小）；PINN 的梯度下降则不然——n=1e4·NA
尖峰要求界面处 φ 有极陡的正曲率来平衡，tanh MLP（光滑、二阶导有界）**无法表达**这么窄这么陡的
尖峰，损失无法下降，优化器把网络推向极端 → 权重 NaN。这是**PINN 相对 FDM 的固有鲁棒性差异**。

**结论与处置**：强反型必须用**电压扫描初值**（phi0 = 上一栅压的收敛解），这正是搭建说明
`solve_sp` 文档本身对 FDM 反型区的建议，Stage 9 的受控对照统一采用（FDM 与 Hybrid 各自自洽
扫描）。用 phi0=φ(Vg=1.0) 时 Vg=1.5 的暂态 n 回到物理量级，PINN 正常收敛。

### 9.4.3 发现三：强反型 Anderson 超调 → 窄瞬态尖峰不可表达，需外层信任域

这是本阶段最关键的发现，经历了一段「早停 → 超调 → 密度限幅 → 信任域」的排查链，最终定位为
**外层迭代的数值稳定性问题，而非内层 PINN 的训练问题**。

**(a) 早停的失败**。最初用 `early_stop=True`（损失停滞即停）时，强反型下损失在 ~7e-2 处平台，
但界面 Robin 残差仍在改善——「损失停滞」不等于「解收敛」，早停把训练停在 Robin≈0.5 的坏极小。
→ 改为**训足固定轮数**（scf_epochs=3000、无早停），内层两阶段收敛到 Robin≈0.004（逐轮诊断验证）。

**(b) 即使训足，守卫仍触发**。Vg=1.5 电压扫描初值（φ_s=893 mV），iter 1 的 Anderson 外推把
φ_s 从 893 mV 超调到 **1128 mV**（超调 49 mV，越过真解 1079.6 mV）。经 n(φ) 的指数灵敏度
（强反型区 ∂ln n/∂φ ≈ 5.5%/mV）放大，这个 49 mV 超调把 n_max 从真解的 ~139·NA 放大到
**~1900·NA** 的窄瞬态尖峰，tanh MLP 无法表达 → 训练发散 NaN（逐轮诊断 + from-scratch 两阶段在
1900·NA 上直接 NaN）。

**超调的机制**：固定点映射 φ = G(φ) 在不动点附近有 dG/dφ < 0（φ 增大 → n 增大 → 屏蔽增强 →
Poisson 解 G(φ) 降低）。残差 r = G(φ) − φ = (1 − dG/dφ)(φ* − φ)，系数 1 − dG/dφ > 1，即残差
**大于**与真解的间隙；Anderson 外推据此放大步长，一步就越过 φ* 造成超调。FDM 内层 Newton 对
超调产生的暂态 n 尖峰**无条件稳定**（总能解出某个 φ 继续迭代）；PINN 内层则**表达不了**这个
窄尖峰，直接崩溃。

**(c) 表达力上限取决于尖峰的「形状」（窄度），不只是 n_max**（逐项诊断验证）：

| 尖峰 | 可表达？ | 证据 |
|---|---|---|
| 400·NA 宽尖峰（Vg=2.0 真解） | ✅ | Robin/D_ref=0.0019 |
| 138.9·NA 窄尖峰（Vg=1.5 真解） | ✅ | Robin/D_ref=0.0040 |
| 500·NA 窄尖峰（截断的瞬态） | ❌ | loss=2.2e4，φ_s 掉回经典解 |
| 1900·NA 窄尖峰（超调瞬态） | ❌ | 训练发散 NaN |

关键洞察：**尖峰越窄，tanh MLP 越难表达**。真解的电子尖峰虽高（Vg=2.0 达 400·NA）但较「宽」
（界面势阱深、波函数展布），可表达；超调产生的瞬态尖峰虽可能更「矮」却更「窄」（尖峰由非自洽
的过高表面势把电子压到最靠近界面的单个子带，展布极窄），不可表达。

**(d) 密度限幅（方案二延伸）的失败**。曾尝试在 step 内把 n 硬截断到 500·NA（高于真解 400·NA、
低于发散 ~1900·NA），期望「只约束瞬态、不碰收敛解」。实测双重失败：
- 截断后的 500·NA 窄尖峰**仍不可表达**（loss=2.2e4，φ_s=1429.6 mV）；
- 硬截断使 G(n) 在 n > cap 处**变平**（n 不再影响 φ），产生一个**伪经典不动点** φ_s=1435.6 mV，
  循环收敛到错误解（带 cap 实测收敛到 1435.6 mV，而真解是 1079.6 mV）。

→ **撤掉密度限幅**（误导且有害）。

**(e) 外层信任域（最终方案）**。问题的源头是 Anderson 外推的**超调**，而非尖峰本身。故在
`_solve_sp` 里对 Anderson 外推后的步长做裁剪：

```python
if max_dphi is not None:
    dphi = phi - x_hist[-1]           # 本步 φ 变化（α·r + Anderson 外推项）
    dphi = np.clip(dphi, -max_dphi, max_dphi)
    phi = x_hist[-1] + dphi
```

`max_dphi_V_pinn=0.02 V`（20 mV）**从源头限制单步 φ 变化**，让 φ_s 在爬升过程中**不会越过
真解太多**，从而不会产生超调导致的窄瞬态尖峰。这是 **PINN 专属**的：FDM 内层对任意 n 稳定，
`max_dphi=None` 不启用（不牺牲 FDM 的收敛速度）。实测 Vg=1.5 以 51 轮、Vg=2.0 以 87 轮收敛到
物理解（φ_s=1079.2 / 1181.6 mV，见 9.5），不再掉进伪不动点。

**代价**：信任域把强反型区的爬升限制在 20 mV/轮，迭代数从 Anderson 理想外推的几轮增加到
~51–87 轮；但每一步都落在可表达区间，**用迭代数换鲁棒性**。这是 PINN 作为 Poisson 子问题
求解器时的一个固有鲁棒性代价，论文中应如实呈现。

**判读**：

- **精度**：φ_s 偏差全程 < 0.5 mV、Ns 偏差 < 1%、rel-L2 < 0.05%；max|Δφ| 在 Vg≤1.5 时 < 1 mV
  （0.47 / 0.77 mV），Vg=2.0 时 2.12 mV——深反型误差集中在界面附近更陡的电子尖峰处。比 Stage 8
  冻结-n 的独立对照（Vg=1.0→0.658 mV、Vg=1.5→3.21 mV）**更准**——因为 warm-start 跨轮累积
  微调把 PINN 逐步「钉」在自洽解附近，而非一次 from-scratch 逼近。
- **Vg=0.5 的「平凡完美」**：见 9.1，弱反型 1 轮收敛、PINN 未实际更新 φ，两者同返经典初值，
  故误差恒 0——不是 PINN 精度，是共享初值所致，如实标注。
- **迭代数**：Hybrid 弱反型 1 轮、中反型 31 轮、强反型 51/87 轮（FDM 为 1 / 11 / 17 / 27 轮）。
  强反型轮数偏多是外层信任域（9.4.3）把单步 φ 变化限制在 20 mV 的直接结果——用迭代数换
  「不超调、不崩溃」的鲁棒性。解本身稳定在 <0.5 mV（φ_s 偏差），δ 在 tol=5e-4 附近由噪声地板决定。
- **效率**：Hybrid 单点 Vg=1.0/1.5/2.0 约 22 / 34 / 59 分钟（31/51/87 轮 × 每轮 3000 轮续训
  ~40 s），远慢于 FDM（毫秒级）。这是预期内的——PINN 的收益不在单点求解，而在 **Stage 12
  参数化推理**（一次训练、任意 (z,Vg) 前向），见 9.7。

## 9.7 风险与后续（Stage 10 交界）

1. **fine-tune 轮数与学习率**：本阶段 warm-start 续训用 scf_epochs=3000、lr=1e-3（沿用首轮），
   未系统调优。Stage 10 正式消融 **from-scratch vs fine-tune**（论文 §3.3 已写「后续 ~500 轮
   @1e-4」的方向）。强反型 51/87 轮偏多，可通过降低续训 lr（噪声地板更低、tol 可更紧）或更
   精细的信任域（随残差自适应放宽）进一步压缩。
2. **信任域参数的敏感性**：max_dphi_V_pinn=0.02 V 是「足够小以防超调、足够大以免爬升过慢」的
   折中，未系统扫参。它是**外层数值稳定**参数（对应 FDM 的 Newton 无条件稳定），与 PINN 网络
   结构无关；若后续换更深/更宽网络（表达能力更强、可表达更窄尖峰），此参数可放宽。Stage 11
   消融可做信任域敏感性。
3. **电压扫描初值的依赖**：Hybrid 在强反型依赖电压扫描 phi0（9.4.2）。若要做「任意 Vg 直接
   求解」的鲁棒性，仍需信任域 + 电压扫描配合；「从零初值直接求解强反型」受 9.4.2 的暂态尖峰
   表达力限制，是 Stage 10/11 的候选方向，不在 Stage 9 范围。
4. **效率收益点**：单点 Hybrid 慢于 FDM（强反型 ~34–59 min/Vg），收益在 Stage 12 参数化推理
   （(z,Vg)→φ 一次训练复用）。本阶段的 wall time 数据是 Stage 12 收益的对照基准。
