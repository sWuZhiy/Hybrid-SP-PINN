# Stage 8：Poisson-PINN 独立求解器（重点）

- **内容**：给定固定 ρ(z)，训练 PINN 解一维 Poisson，逼近 FDM。Schrödinger/EF/SCF 一律不介入。

### 物理内涵与模型

**模型**：PINN 把解 φ 参数化为神经网络 `φ_θ(z)`，通过最小化 PDE 残差的均方损失逼近真解；本质是**强形式 + 配置点**的偏微分方程求解器，与传统 FDM 的弱形式/通量形式形成对照（详见 §8.1）。

- **PDE 残差损失**：真解使 Poisson 残差处处为零，故 `L=mean(R²)` 可作为训练目标（Raissi et al. 2019）。
- **硬约束（Hard Constraint）**：`φ_hat=φ_BC+d(z)·NN` 中 `d(0)=d(L)=0` 使边界条件被架构本身保证，BC 损失可移除、边界精度大幅提升。
- **强形式 vs 弱形式**：PINN 逐点强制微分方程，而 FDM 强制积分守恒——这一区别在介电界面处放大为「光滑网络能否表示导数跳变」的根本难题（§8.1）。

  - [src/poisson_pinn.py](../src/poisson_pinn.py)（已建）：`PoissonPINN(nn.Module)`、硬约束 `phi_hat = φ_BC + d(z)·NN`、损失、训练循环、`PoissonPINNSolver`（warm_start/seed/loss_history/wall_time）、`solve_poisson_pinn`（n 非零时默认两阶段课程学习）。
  - [tests/test_poisson_pinn.py](../tests/test_poisson_pinn.py)（已建）：6 项测试（平带、drop-in 经典对照、冻结 n 对照、边界精确、界面 D 连续、输入校验）。
  - [experiments/07_poisson_pinn.py](../experiments/07_poisson_pinn.py)（已建，初稿）：经典 Vg 0.5/1.0 + 冻结 n Vg=1.5 对比图。

### 8.1 关键差异：为什么 FDM 没有界面难题，PINN 却有

这是本阶段、乃至整个 Hybrid PINN 方案**最核心的数值差异**，须在论文中讲清楚。

**FDM（Stage 3）是「有限体积 / 通量形式」，从不跨界面求导。**

其离散式（[src/poisson_fdm.py](../src/poisson_fdm.py)）为：

```
k[i-1]·φ[i-1] − (k[i-1]+k[i])·φ[i] + k[i]·φ[i+1] = −ρ[i]·cvw[i]
k[i] = ε_half[i] / dz
```

界面处半网格 ε 取**调和平均** `ε_half = 2·ε_ox·ε_si/(ε_ox+ε_si) = 5.85 ε₀`。FDM 只操作**节点上的 φ 值**和**相邻节点间的通量**，从不求 ε 的导数，也不求 φ 跨界面的二阶导。导数跳变被「编码」进界面处 ε_half 里，电位移连续 `ε_ox·E_ox = ε_si·E_si` **自动且精确**满足。

实测（耗尽剖面、Vg=1.5 V）：

```
氧化层侧电场  E_ox  = 6.435e7 V/m
Si 侧电场     E_si  = 2.144e7 V/m
E_ox / E_si         = 3.002   （理论值 ε_si/ε_ox = 3.000）
```

**PINN 是「配置点 / 强形式」，用全局光滑函数逐点求导。**

1. φ(z) 是 tanh 网络，**处处无穷可微**，`dφ/dz`（autodiff）必然连续。而真实解要求它在界面**跳 3 倍**（`E_si = E_ox/3`）。光滑函数**表示不了不连续导数**——这是「表示能力」硬伤，不是「训练不够」。
2. 若按散度形式写残差 `−d/dz(ε·dφ/dz)`，autodiff 求 `dε/dz` 时在界面得到 **Dirac δ**（ε 是阶跃），autodiff 不处理 δ，直接算错。
3. 若按方案B §4.3 的拉普拉斯形式 `d²φ̄/dz̄² + ρ̄`，等于**假设 ε 均匀**，把 3 倍介电跳变整个丢掉，物理上错。

**一句话总结**：FDM 用调和平均把介电界面「免费消化」；PINN 必须**显式处理**界面条件，否则凭空多出一个「假界面电荷」的误差。

### 8.2 由此推导的正确实现方案

利用「理想氧化层无电荷 → φ_ox 严格线性」这一模型一致性：

```
φ_ox(z) = Vg − (Vg − φ_s)·z/t_ox，  φ_s = φ(t_ox)
```

- **推荐**：解析氧化层 + Si 区单网络。网络只在 `[t_ox, L]` 求解；硬约束满足 `φ(L)=0`；界面加一条 Robin 软损失 `[ε_si·φ_si'(t_ox) + ε_ox·(Vg−φ_si(t_ox))/t_ox]²` 保证 D 连续（注意加号：氧化层 φ 线性 → φ'_ox=(φ_s−Vg)/t_ox，D 连续 `ε_si·φ'_si=ε_ox·φ'_ox` ⟹ `ε_si·φ'(t_ox)+ε_ox·(Vg−φ_s)/t_ox=0`）；PDE 损失仅在 Si 区（ε_si 常数，无跳变，autodiff 干净）。氧化层解析重建，零误差、无 kink。
- **消融 1（文档强制）**：hard vs soft BC。
- **消融 2（更有价值）**：naive 全域单网络 + 拉普拉斯残差，量化「丢界面跳变」的误差——本身就是一张有力对比图。

### 8.3 无量纲化（方案B §3.5 有误，须修正）

- 方案B 用本征德拜长度 `L_D=√(ε_si·kT/(q²·n_i))`，代入得 **L_D≈33 μm**，而器件仅 102 nm，`z̄∈[0,0.003]`，输入被压缩到近 0，是灾难性尺度。
- **修正**：纯 Poisson（固定 ρ、无 Boltzmann 项）用几何尺度 `z̄=z/L_total∈[0,1]` + `φ̄=φ/V_ref`；残差除以 `ρ_ref=ε₀·V_ref/L_total²` 归一化到 O(1)。热电压标幺 `φ̄=qφ/kT` 只在耦合 Boltzmann 载流子项（Stage 9 全 SP）时才需要。

### 8.4 前向风险：容差不匹配

SCF 收敛判据 `tol_V=1e-6 V`，而 PINN-Poisson 单次调用只能到 ~1e-3~1e-4 V。Stage 9 里 SCF 会收敛到「PINN 的近似解」而非真解，误差地板由 PINN 精度决定。**现在就要定**：Stage 8 精度目标 = 相对 L2 < 1e-3；论文明确 Stage 9 对比的是「PINN 逼近的 SCF 解 vs FDM 精确 SCF 解」。

### 8.5 代码 ↔ 物理对应（计划）

| 物理量 | 计划代码 |
|---|---|
| 硬约束 `φ_hat(z)=φ_BC(z)+d(z)·NN(z)`，`d(0)=d(L)=0` | `phi_hat = phi_BC + d * NN(z)`，`d = (z/L)(1-z/L)` |
| PDE 残差 `-d²φ̄/dz̄² - ρ̄`（Si 区，ε_si 常数） | autodiff 二阶导，残差按 `ρ_ref=ε₀V_ref/L_total²` 归一化 |
| 界面 D 连续 `ε_si·φ_si'(t_ox)+ε_ox·(Vg−φ_s)/t_ox=0` | `L_iface = (ε_si*φ'(t_ox) + ε_ox*(Vg−φ_s)/t_ox)²` |
| 总损失 `L = L_pde + λ·L_iface` | `loss = mean(R²) + λ_iface * L_iface` |
| 输出装配（氧化层线性重建） | `φ_ox = Vg − (Vg−φ_s)·z/t_ox`，与 Si 解拼接 |

### 8.6 最终实现方案（定稿）

**替代对象**：非线性 Poisson `-d/dz(ε dφ/dz)=q[p(φ)-n-NA]`，与 `solve_poisson_nonlinear` 同签名，Stage 9 可一行替换（drop-in）。

**六条核心决策**：

1. **界面处理 = 解析氧化层 + Si 单网络**：利用 ρ_ox=0 → φ_ox 严格线性，把氧化层解析掉（`φ_ox(z)=Vg−(Vg−φ_s)·z/t_ox`），PINN 只在 Si 区求解；界面用一条 Robin 软损失 `ε_si·φ_si'(t_ox)+ε_ox·(Vg−φ_s)/t_ox=0` 保证 D 连续（加号推导见 §8.2）。彻底规避「光滑网络无法表示导数跳变」的难题，且氧化层零误差。
2. **标幺化**：`u=(z−t_ox)/L_si∈[0,1]`（几何长度）、`φ̄=qφ/kT`（热电压）——热电压使 Boltzmann 空穴项退化为 `p=NA·e^{−φ̄}`，从源头避免指数溢出（Stage 9 的 p(φ) 项由此受益）。
3. **硬约束**：`φ̄(u)=(1−u)·NN(u)` 强制 `φ(L)=0`；界面 Robin 恒为软损失。`hard_constraint` 开关作为消融。
4. **状态管理**：`PoissonPINNSolver` 持有 `nn.Module`，`warm_start`（True=续训 / False=随机初始化）+ `seed` 固定随机种子——为 Stage 10 的 from-scratch vs fine-tune 对比铺路。
5. **损失归一化**：`L=mean(R_pde²)+λ_iface·R_iface²`，其中 `R_pde` 除以 `q·NA`、`R_iface` 除以参考 D 均归一化到 O(1)。
6. **两档验证**：① 固定 n（如 n=0 经典耗尽）→ 对照 `solve_poisson_nonlinear`；② 冻结 Stage 7 自洽 n → 对照同函数。两者用同一套 PINN 机制。

**两条概念澄清（已与用户确认）**：
- **训练不依赖经典结果**：PINN 无监督，损失只有 PDE 残差 + 边界条件，FDM 的 φ 仅作**验证基准**、绝不作训练标签；但混合循环里 PINN 的输入 ρ/n 来自经典薛定谔模块（物理耦合，非「学习」）。
- **单点 PINN 不鲁棒、不普适**：每个 (ρ,Vg) 训练一次，换题必重训；只有 Stage 12 的参数化 PINN 才有训练分布内的泛化。论文须写准此定位。

### 8.7 数值验证结果（实测）

验证方式：PINN vs FDM Newton（同一方程、同一冻结 n、同一边界 φ(0)=Vg/φ(L)=0）。

| 情形 | max\|Δφ\| | mean\|Δφ\| | φ_s (PINN/FDM) | 耗时 | 结论 |
|---|---|---|---|---|---|
| n=0, Vg=0.5（经典耗尽） | 0.685 mV | 0.198 mV | 0.4317 / 0.4324 | 30 s | ✓ |
| n=0, Vg=1.0（经典耗尽） | 0.658 mV | 0.416 mV | 0.8994 / 0.8998 | 28 s | ✓ |
| 冻结 n, Vg=1.5（强反型）直接训练 | 1137 mV | 373 mV | −0.057 / 1.080 | 28 s | ✗ 错误势阱 |
| 冻结 n + λ_iface=10（无课程） | 711 mV | 305 mV | 0.369 / 1.080 | 38 s | ✗ 权重调大无效 |
| 冻结 n + n-ramp 课程（4000 轮） | 8.64 mV | 3.81 mV | 1.0710 / 1.0796 | 38 s | ✓ |

| 冻结 n，默认 config（两阶段 1500+1500 轮） | **3.21 mV** | 0.77 mV | 1.0765 / 1.0796 | 29 s | ✓ 默认设置复现 |
| soft-BC 消融（hard_constraint=False，经典 n=0, Vg=1.0） | **53.94 mV** | 26.06 mV | —（φ(L)=0.13 mV） | 44 s | ✗ 比硬约束差 ~80 倍 |

**强反型直接训练失败机理（鸡-蛋冲突，可写进论文）**：

界面 Robin 的斜率目标随 φ_s 变化：`φ'(t_ox) = −(ε_ox/ε_si)·(Vg−φ_s)/t_ox`。训练初期 φ_s≈0 ⟹ Robin 要求 dφ̄/du(0) ≈ **−967**（φ̄ 单位，巨陡负斜率）；而强反型电子尖峰（n ≈ 10²·NA）要求该处 φ̄″ ≈ +58 的正曲率——两者在 u=0 处方向冲突。网络逃入 φ_s<0 的错误势阱（那里 p=NA·e^{+|φ̄|} 指数暴涨，恰好「对冲」电子尖峰），损失平台在 0.92。调大 λ_iface 无效（711 mV）证明这是**方向冲突而非权重失衡**。

**修复：课程学习（两阶段续训）**，即先以 n=0 训练经典解（φ_s 升到 ~1.3 V，Robin 斜率目标温和化），再 warm_start 续训满 n（电子尖峰变成对既有解的扰动）。这与 Gummel 外层「先经典、后量子」的物理顺序一致，且正是 Stage 9 fine-tune 的工作流。已作为 `solve_poisson_pinn` 的默认策略（n 非零时自动两阶段，各占一半轮数）；单阶段 n-ramp 作为消融选项保留。

**指标对照论文承诺（MAE<0.02 V、rel-L2<2%）**：实测 MAE 0.2–1.5 mV、rel-L2 ~10⁻³ 量级——**远超承诺，论文指标安全**。

**补测结论（2026-08-17）**：① 默认 config 下两阶段课程（1500+1500）冻结 n 精度 3.21 mV——默认设置直接可用，容差 25 mV 富余 7 倍；② soft-BC 消融 53.94 mV（硬约束 0.658 mV）——硬约束带来 ~80 倍精度提升，为论文「硬约束必要性」提供实测证据（soft-BC 的 BC 本身满足得很好：φ(L)=0.13 mV，误差来自 PDE 残差在边界附近的分配恶化，而非 BC 未满足）。
