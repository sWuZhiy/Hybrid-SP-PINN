# Stage 12：有监督参数化神经代理（可选 / 展望，不纳入核心贡献）

> 本阶段原稿写成「(z, Vg) → φ 的参数化 PINN，跳过自洽循环」。经算法/物理审查判定
> 该表述概念有误（详见 §12.2、§12.3），**重写如下**，并据用户决定**当前不做**（§12.5）。

## 12.1 定位：这是「代理模型 (surrogate)」，不是「物理信息 PINN」

「参数化神经网络替代自洽循环」在 Schrödinger–Poisson 语境下**只可能是有监督代理模型**：

- 训练数据 = 在 train Vg 上跑**完整自洽求解**（FDM-SP 或 Hybrid SP-PINN）得到的标签 φ(z; Vg)；
- 网络学到的是 (z, Vg) → φ 的**插值映射（数据驱动）**，不是从 Poisson PDE 残差最小化学到的
  **物理约束解**；
- 因此它**不是 physics-informed**，与本项目核心贡献（Stage 8–10 的**无监督** Hybrid PINN）
  是两种性质不同的东西，论文里**不得混称「参数化 PINN」**。

## 12.2 为什么「无监督参数化 PINN 跳过自洽」在现有架构下不可行

自洽的 φ 依赖量子密度 n(φ)，而 n(φ) 经 Schrödinger 本征值问题得到：

- 现有 Schrödinger 用 FDM 三对角对角化（scipy `eigh_tridiagonal`，见 [stage4.md](stage4.md)），
  **非 torch、不可微**；
- n(φ) = Σᵢ |ψᵢ(φ)|² · f(Eᵢ(φ)) 中的 Eᵢ、ψᵢ 都来自这个不可微的本征值求解 → **无法对 φ 求
  n 的梯度**；
- 故无法把「自洽 φ」写进无监督 PDE 损失（反向传播穿不过 Schrödinger）。

Gummel 循环（[stage7.md](stage7.md)）正是靠**把不可微的 Schrödinger 与可微的 Poisson 解耦
交替求解**绕开这一点。要「一个网络端到端跳过循环」，只有两条路：

1. **有监督代理**（本阶段定位）：标签来自完整 SP 求解；
2. **把 Schrödinger 也 PINN 化**（再搭 (z,Vg)→{Eᵢ,ψᵢ} 网络，双 PINN 耦合端到端训练）——
   这是全新研究方向，远超「可选」定位，**本毕设不做**。

## 12.3 引用修正（原稿引用错位）

原稿把 DDNet / DAC 引作 Stage 12 技术路线的支撑，**错位**：

- Riganti 2025 (DDNet)、Cai 2024 (DAC) 解的是**耦合泊松 + 漂移扩散方程组**（纯 PDE、
  点态残差、可微），故能把整个耦合系统嵌入损失端到端训练；
- 本项目是 **Schrödinger–Poisson**（含本征值问题，非点态 PDE），**不能照搬**「全嵌入
  损失」路线。

**正确用法**：DDNet/DAC 仍保留在 [references.md](references.md) §A.3，但归位到
「§1.2 研究现状：PINN 替代传统 TCAD 求解器」与「§5 展望：参数化替代方向」——
它们支撑**立意**（用神经网络替代/加速 TCAD 扫描），**不支撑本阶段的「跳过 SP 自洽」
具体技术路线**。本阶段 surrogate 本身属「神经网络通用函数逼近 / 代理模型」，引用
**Cybenko 1989**（通用逼近定理，条目 18）/ **Hornik 1991**（条目 19），已核实 DOI 并写入
[references.md](references.md) §A.5。

## 12.4 设计要点（其余修正项，若将来落地须遵守）

- **输出完备性**：若网络只输出 φ(z,Vg)，推理时仍须**跑一次 Schrödinger 对角化**才能得到
  n/Eᵢ/Ns——「跳过自洽循环」≠「跳过 Schrödinger」。设计须明确 surrogate 的输出范围
  （φ only，或 φ+n+Eᵢ+Ns 多输出）。
- **泛化边界**：φ(Vg) 在反型起始（本器件 ~1.0–1.2 V）有非线性拐点，surrogate 的插值误差
  最容易在此被低估。**held-out Vg 必须含拐点附近点**，且只能报告训练范围内的内插精度；
  **严禁**用训练点测试、严禁「任意栅压泛化」。
- **成本与收益**：标签 = N_train 次完整 SP 求解；收益只在 test Vg ≫ train Vg 时成立。
  须与 [stage11.md](stage11.md) 的多栅压总成本放在一起对比才有意义（RQ4 的「摊销版」答案）。
- **2D 输入实现**（次要）：Vg 需归一化（z ~ 100 nm 与 Vg ~ 1 V 量纲差两个数量级）；
  Robin 损失 / 配点 / 硬约束按 Vg 批处理；训练配点从 1D 变 2D (z,Vg) 网格。

## 12.5 定位结论

- 本阶段为**可选 / 展望**，不纳入核心贡献，论文「§5 展望」一句带过：
  「未来可用有监督参数化神经代理在训练栅压范围内快速预测自洽电势，但不能外推、不属
  物理信息路线」。
- **当前决策：不做**（Stage 11 的 RQ4 已能回答「参数化替代是否划算」的动机问题）。
  若将来要做，按 §12.2 路线 1（有监督）落地，并补 §12.4 的拐点 held-out 采样。
