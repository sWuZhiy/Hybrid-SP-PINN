# Stage 1：物理常数与单位

- **内容**：集中定义 SI 物理常数与单位换算，杜绝业务代码散落魔法数字。

### 物理内涵与模型

- **基本电荷 `q`**：电荷量子化的最小单元，也是 `eV` 与 `J` 的换算桥（`1 eV = q J`，一个电子经 1 V 电势差加速获得的能量）。
- **约化普朗克常数 `ħ`**：量子力学的作用量单位，出现在薛定谔方程与态密度中；`ħ²/(2m)` 是动能算符的前因子。
- **玻尔兹曼常数 `kB`**：温度与能量的换算，`kT` 是热运动特征能量（300 K 时 `kT≈0.02585 eV`）。
- **真空介电常数 `ε0`**：真空电容率，Poisson 方程里 ε 的基准。
- **单位约定**：内部一律 SI 保证各方程量纲自洽；仅绘图/输出时换算到 nm、eV、cm⁻³。
- **涉及文件**：
  - [src/constants.py](../src/constants.py)：`q`、`hbar`、`m0`、`kB`、`eps0`。
  - [src/units.py](../src/units.py)：能量（eV↔J）、长度（nm↔m）、浓度（cm⁻³↔m⁻³）换算。
  - [tests/test_units.py](../tests/test_units.py)：5 项测试。
- **要点**：内部计算统一 SI，仅绘图/输出时换算。`1 eV = q J` 严格成立，故 `EV_TO_J = q` 直接复用常数。

**代码 ↔ 物理对应：**

| 物理量 | 代码符号 | SI 值 |
|---|---|---|
| 基本电荷 | `constants.q` | 1.6022e-19 C |
| 约化普朗克常数 | `constants.hbar` | 1.0546e-34 J·s |
| 电子静止质量 | `constants.m0` | 9.1094e-31 kg |
| 玻尔兹曼常数 | `constants.kB` | 1.3806e-23 J/K |
| 真空介电常数 | `constants.eps0` | 8.8542e-12 F/m |

单位换算：`units.EV_TO_J = q`（1 eV = q J 严格成立）、`NM_TO_M = 1e-9`、`CM3_TO_M3 = 1e6`。
